# Planner

Google カレンダーと連携する、タスク・スケジュール管理アプリ。
インストールするものはありません（macOS に入っている Python だけで動きます）。

## 起動

```bash
python3 planner/serve.py
```

ブラウザで <http://localhost:5173> を開きます。

## できること

- **月 / 週 / タスク** の 3 つの表示
  - 月: 1 か月の予定とタスク。日をクリックすると右側にその日の詳細とメモ
  - 週: 時間軸つきの 1 週間。下段に日ごとのメモ、右側に週のメモ
  - タスク: 1 週間を日ごとの列に並べ、完了数・進み具合・その日のメモをまとめて表示
- **メモ**: 日ごと・週ごと。入力するとすぐ保存され、Google ドライブ経由で他の端末と同期
- **スマホ・タブレット対応**: 画面幅に合わせた表示。ホーム画面に追加してアプリのように使える
- **Google 連携**（双方向）
  - アプリの「予定」 ⇔ Google カレンダーの予定
  - アプリの「タスク」 ⇔ Google ToDo リスト（Google カレンダー上にもタスクとして表示されます）
- ドラッグ＆ドロップで日付を移動、削除の「元に戻す」

## Google 連携の準備（初回のみ）

アプリ右上の設定（スライダーのアイコン）にも同じ手順とリンクがあります。

1. [Google Cloud Console](https://console.cloud.google.com/projectcreate) でプロジェクトを作成
2. 「API とサービス → ライブラリ」で **Google Calendar API**・**Google Tasks API**・**Google Drive API** を有効化
   （Drive はメモの同期用。使うのはこのアプリ専用の隠し領域だけで、ドライブの他のファイルは見えません）
3. 「Google Auth Platform」で同意画面を設定（対象:「外部」、テストユーザーに自分のアカウントを追加）
4. 「クライアント → クライアントを作成」で種類「ウェブ アプリケーション」を選び、
   「承認済みの JavaScript 生成元」に `http://localhost:5173`、
   「承認済みのリダイレクト URI」に `http://localhost:5173/` を追加
5. 発行されたクライアント ID を設定画面に貼り付けて「Google と接続」

## スマホや iPad で使う（インターネット上に置く）

`web` フォルダの中身だけで動くので、静的サイトを置けるサービス（Netlify、Cloudflare Pages、GitHub Pages など）に
`web` フォルダをそのままアップロードします。置いたあとに Google Cloud のクライアントへ次の 2 つを追加します
（`https://example.netlify.app` の部分は実際のアドレスに読み替え）。

- 承認済みの JavaScript 生成元: `https://example.netlify.app`
- 承認済みのリダイレクト URI: `https://example.netlify.app/`（末尾の `/` まで一致させる）

スマホでそのアドレスを開き、「Google と接続」を押せば使えます。クライアント ID は `web/js/config.js` に
入っているので、端末ごとの入力は不要です（クライアント ID は公開してよい識別子です）。
iPhone / iPad では Safari の共有メニューから「ホーム画面に追加」でアプリのように使えます。

- インターネット上の版はサーバーを持たないので、接続は約 1 時間で切れます（「再接続」を押すとすぐ戻ります）。
- メモは Google ドライブのアプリ専用領域に保存され、Mac とスマホで同じ内容になります。
  同じメモを 2 台で同時に書き換えた場合は、あとから書いたほうが残ります。
- アプリを更新したら、`web` フォルダをもう一度アップロードします。

## ノート（文字と手書き）

上部の「ノート」タブで、日・週・月ごとのページを開けます。1 ページに、キーボードで打つ文字と手書きの両方を書けます。

- 文字は、他の画面のメモ欄（日のメモ・週のメモ・月のメモ）と同じものです。
- 手書きは iPad の Apple Pencil 向けです。ペンは書く・指はスクロールで、「指で書く」をオンにすると指でも書けます。
  Mac ではマウスでも書けますが、主にキーボード入力と手書きの閲覧用です。
- 道具: ペン 4 色・太さ 2 種類・消しゴム（なぞった線を消す）・元に戻す・全部消す・ページを下に伸ばす。
- 手書きがあるメモは、月表示の右パネルや今日の一覧に小さなプレビューが出ます。押すとノートが開きます。
- 手書きも Google ドライブのアプリ専用領域に保存され、端末間で同期されます（同じページを 2 台で同時に
  書き換えた場合は、あとから書いたほうが残ります）。

## 今日の一覧（小さな窓に置いておく画面）

`today.html` は、今日の予定・タスク・期限切れ・メモと明日の予定だけをまとめた画面です。
進行中の予定には色が付き、終わった予定は薄くなります。

- **Mac**: Safari で `http://localhost:5173/today.html` を開き、「ファイル → Dock に追加」で小さな窓のアプリにできます
  （Chrome なら「保存して共有 → ページをアプリとしてインストール」）。
- **スマホ / iPad**: 公開先の `today.html` を開いた状態で「ホーム画面に追加」すると、専用のアイコンになります。
  ホーム画面のアイコンごとにデータの保存場所が分かれるので、初回だけ「Google と連携」が必要です。

ホーム画面に常時表示される本物のウィジェットではなく、開いて見る画面です。

## 接続を切れなくする（任意・この Mac で使うとき）

上の手順だけでも使えますが、その場合は約 1 時間ごとに「再接続」が必要です。
次の設定をすると、同梱サーバー（`serve.py`）が接続を保ち、操作なしで自動更新されます。

1. Google Cloud の同じクライアントで、「承認済みのリダイレクト URI」に
   `http://localhost:5173/api/auth/callback` を追加
2. 同じ画面でクライアント シークレットを発行（「Add secret」）
3. アプリの設定画面の「シークレット」欄に貼り付けて保存し、接続し直す

シークレットと更新用トークンは、この Mac の `~/.config/planner/auth.json`（自分だけが読める権限）に
保存されます。ブラウザに渡るのは短時間だけ有効なアクセストークンのみです。
設定画面の「接続を解除」で Google 側の許可を取り消し、シークレットの「削除」でファイルごと消えます。

Google Cloud の同意画面が「テスト中」の間は、Google の仕様でこの接続も 7 日で切れます
（切れたら「再接続」を押すだけです）。「Audience」ページで「Publish app」を押して公開状態にすると
7 日の制限がなくなります。自分用であれば Google の審査は不要です。

## 知っておくとよいこと

- 上の設定をしない場合、接続は約 1 時間で切れます。切れている間の変更は手元に残り、
  「再接続」を押すとまとめて送られます。
- Google ToDo リストの仕様上、タスクの期限は「日付」だけです（時刻は持てません）。
- メモは、Google に接続している間は Google ドライブのアプリ専用領域にも保存されます（他の端末と同期）。
  未接続のときはこのブラウザの中だけです。設定の「バックアップ」からファイルに書き出せます。
- 取り込む期間は、今日の半年前〜1 年後（表示中の月がそこから外れると自動で取り直します）。

## Mac の起動時に自動で立ち上げる

`~/Library/LaunchAgents/com.planner.server.plist` を置くと、ログイン時にサーバーが自動で起動します
（中身は `python3 -u serve.py 5173` を常駐させる設定。ログは `~/Library/Logs/planner-server.log`）。

```bash
launchctl kickstart -k gui/$(id -u)/com.planner.server   # 再起動（serve.py を書き換えたあと）
launchctl bootout gui/$(id -u)/com.planner.server        # 止める（plist を消せば自動起動もやめられる）
```

## テスト

サーバーを起動した状態で次のページを開くと、模擬 Google サーバーを使ったテストが走ります。
アプリ本体のデータには触れません。

- <http://localhost:5173/tests.html> … 日付計算・データ変換・同期の流れ（ブラウザだけの方式）
- <http://localhost:5173/tests.html?backend> … 接続を保つ方式（自動更新、失効時の再接続待ち）

同梱サーバーの認証 API のテスト:

```bash
python3 planner/test_server.py
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `web/js/store.js` | 状態と保存（localStorage） |
| `serve.py` | この Mac で使うときのサーバー（`web` の配信と、接続を保つための認証 API） |
| `web/` | アプリ本体。このフォルダだけでインターネット上に置ける |
| `web/js/config.js` | クライアント ID の初期値 |
| `web/sw.js` / `web/manifest.webmanifest` | ホーム画面への追加と、電波がないときの起動用 |
| `web/js/backend.js` | 同梱サーバーの認証 API の呼び出し |
| `web/js/google.js` | Google の認証・API 呼び出し・データ変換 |
| `web/js/sync.js` | 接続状態と双方向同期 |
| `web/js/model.js` / `js/dates.js` | 並び順・マージ・日付計算などの純粋なロジック |
| `web/js/views/*.js` | 月・週・タスク・ノート・今日の一覧の各表示と右パネル |
| `web/js/ink.js` / `web/js/inkpad.js` | 手書きの保存（IndexedDB）と、手書き用キャンバス |
| `web/js/dialogs.js` | 編集ダイアログ・設定 |
| `web/js/dom.js` / `js/ui.js` | 描画の仕組みと共通部品 |
